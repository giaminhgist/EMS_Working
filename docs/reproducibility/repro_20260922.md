set amplifies small trajectory differences (each flip = 0.025 acc).

## Verdict

1. **Classical baselines: reproducible bit-exactly** (8/10 methods; every
   number quoted in `experiment_tracker.md` — SVM-RBF 0.8793, LogReg 0.8711,
   RF 0.8631, P2 0.9075/0.9058 — is reproduced exactly).
2. **Proposal 001–006: reproducible at the level of the tracker's claims.**
   Aggregate 5-seed AUC shifts are ≤ 0.011, within the recorded seed spread
   (±0.005–0.016). Config ranking is preserved: `mlp_norm01` still best
   (0.9453), `mlp_mean` still second, both comparator ablations (`sub`,
   `zsub`) still clearly below the learned comparator (as recorded). No
   recorded conclusion in the tracker changes.
3. **FNN baselines: not numerically reproducible across devices.** Same code,
   same seed, same data → different model on CPU vs GPU. Deterministic on a
   fixed device. This is a caveat to state for any FNN-based claim, not a
   pipeline bug.
4. **Root causes of the (bounded) divergence**, consistent with the evidence
   that sklearn models are bit-exact while every torch-trained model shifts:
   (a) CUDA vs CPU RNG sequences from the same seed (batch order diverges
   from epoch 1); (b) GPU float reduction-order nondeterminism (larger in
   BatchNorm-based FNN, smaller in the LayerNorm-based proposal); (c)
   early stopping and the 0.5 decision boundary amplifying trajectory noise
   into metric swings.
